指标来源与结论边界

  • 吞吐与分位延迟来自 memtier_benchmark 输出；Pipeline 场景的延迟是每批请求延迟，不是单条命令延迟。
  • macOS 上的 Linux 容器运行于 Docker 虚拟机，结果包含虚拟网络与虚拟存储的影响，不代表生产容量。
  • 资源上限是容器配置配额，不是专用物理核或实际使用量；Redis CPU 来自 INFO 的进程 CPU 增量，含后台线程，不等同于主线程占用。
  • 压测端 CPU 接近配额的点已标记，其结果可能受压测端限制，不能当作 Redis 的性能上限。
  • 持久化场景的磁盘为 Docker VM 虚拟存储，不代表物理磁盘 fsync 性能；慢命令场景的后台频率固定，不代表生产延迟。

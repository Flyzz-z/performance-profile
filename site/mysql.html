指标来源与结论边界

  • p95 为延迟直方图近似值；p99 为 sysbench 原生分位数输出。两者均按测试事件 / 事务计量。
  • 点查与索引更新每事件 1 条查询，标准读写混合每事件 20 条查询。TPS 不等同于单条 SQL 的执行速度。
  • macOS 上的 Linux 容器运行于 OrbStack 虚拟机，结果包含虚拟化和本地存储影响，不代表生产容量。
  • 资源字段为记录的配置上限；未采集实时 CPU 或 I/O 瓶颈，不将观察到的拐点视作已证实的瓶颈。
